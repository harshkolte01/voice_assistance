# Authentication UI polish

## Summary

Refined the React Native login and registration screens for clearer hierarchy, consistent Android rendering, and better small-screen behavior.

## Changes made

- Added a shared AuthScaffold with responsive width constraints, safe scrolling, keyboard dismissal, and subtle theme-aware background accents.
- Reworked the brand header into a compact voice-wave identity with left-aligned page copy.
- Refined the authentication card shape, spacing, accent rule, shadow, and ambient detail.
- Replaced platform-dependent emoji icons with lightweight React Native view-based email, person, and lock icons.
- Shortened the visible password actions to Show / Hide while preserving descriptive accessibility labels.
- Removed duplicated screen padding that made forms cramped on narrow Android devices.
- Preserved login, registration, validation, session-expired modal, and navigation behavior.
